One line, spoken in the elevator's own voice:

> I have seen things. Mostly your floor, again, because you pressed all of them.

`main.ts` writes that line to `entry.txt` in the output directory
(`$MAKEFUN_OUTPUT_DIR`, or `out/` by default), with no trailing newline,
and checks it against the 1–120 character gate before writing.
